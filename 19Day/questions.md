#Preguntas
1. Un set puede tener valores repetidos? -> Falso, es una collecion de valores unicos y cada valor puede ocurrir 1 sola vez
2. Como puedo crear un set? -> con `new Set()` 
3. Como puedo verificar que mi objeto set realmente sea un set -> usando el metodo `instanceof Set`
4. Un set tiene keys()? -> Falso son los valores del set que son retornados como llaves
5 Si tengo 2 sets y quiero unirlos que metodo es el mas recomendado para hacer esto? -> `union()`
6. Que son los weakSets? -> Son la coleccion de valores donde son objetos
7.En los maps como puedo obtener el valor de una llave? -> `.get()` y dentro el nombre de la llave
8.Un Objeto map es lo mismo que un metodo map? -> No, son dos cosas distintas, el primero es una agenda o diccionario el segundo un ciclo que transforma elementos en una lista
9.Para que me sirve el .length en un map? -> Para nada eso no sirve se utiliza size()
10. Cual es el objetivo de un objeto Map? -> su objetivo es asegurar un orden al objeto y proporcionar una estructura de datos optimizada, y poder acceder a estos mas facilmente
